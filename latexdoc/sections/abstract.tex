\begin{abstract}

\textbf{Objective}: To develop and validate a fully automated, training-free computational pipeline for scratch-wound quantification that enforces a per-column monotonic closure constraint, eliminating the non-biological area fluctuations produced by frame-independent segmentation.

\textbf{Materials and Methods}: A training-free pipeline segments phase-contrast time-lapse images using local variance--based texture analysis with RANSAC outlier rejection and Savitzky--Golay boundary smoothing, operating in $O(HW)$ per frame. A per-column Kalman filter with a hard monotonic safety net enforces strictly non-increasing boundary evolution. The pipeline was evaluated on 134 phase-contrast images from two independent experiments and two cell lines (iMC~ISOR544C and iMC~MUTR544C) across three culture conditions (ALK5 inhibitor at $0.1\,\mathrm{mM}$, DMSO vehicle, and media control), used as a test bed to assess whether the pipeline resolves condition-dependent closure dynamics.

\textbf{Results}: Expert review confirmed 98.4\% detection accuracy across 124 wound-bearing image. The automated quality-control module achieved a sensitivity of 1.00 for wound detection (NPV = 1.00; Cohen's $\kappa$ = 0.90 against expert verdicts). The temporal constraint yielded strictly non-increasing area trajectories by construction, with a monotonic-constraint across all approved trajectories. A linear mixed-effects model fit to the resulting edge-displacement trajectories detected a significant closure-over-time effect ($\beta = 0.88$~px/frame, $p < 10^{-12}$), demonstrating that the pipeline is able to capture differences between the experiments. 

\textbf{Conclusion}: The proposed pipeline offers a training-free of supervised deep-learning segmenter or manual parameter tuning; the temporal constraint removes the non-biological area fluctuations that accumulate when frames are processed independently. The resulting trajectories are physically consistent and structured for post hoc statistical analysis. The implementation is released in GitHub \citep{Ricciardiello2025code}.

\end{abstract}

\noindent\textbf{Keywords:} scratch-wound assay, automated segmentation,
monotonic closure constraint, local-variance texture analysis, Kalman filter,
temporal constraint, training-free image analysis
