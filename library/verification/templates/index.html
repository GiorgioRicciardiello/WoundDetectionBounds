Annotation Guide

Workflow

  1. Click a row in the left table to load an image.
  2. Review the Diagnostic Panel (left) — shows the 6-panel debug output: original image, variance map, Y-profile, raw edges, smoothed edges, and final mask with QC verdict.
  3. Review the Interactive Annotation canvas (right) — shows the raw image with the model mask overlaid in red.
  4. Click Correct or Incorrect to record your verdict. The tool auto-saves and advances to the next image.
  5. Optionally draw corrections (see below) and click Compute Metrics to quantify the model error.

Drawing modes

Edge Correction (default, recommended)

The model detects the wound as a band between an upper edge (cyan line) and a lower edge (magenta line). When the boundary is mostly correct but off in a region:

  1. Select "Correct upper edge" or "Correct lower edge".
  2. Click points along where the real boundary should be, within the x-range that is wrong. You only need 3–5 points.
  3. Click Finish segment (or double-click) to lock it in. The correction appears in green (upper) or purple (lower).
  4. You can add multiple segments (upper and lower independently).
  5. Click Compute Metrics to see how the corrected mask compares to the original model mask (Dice, IoU, etc.).

Columns outside your correction keep the original model edge.

Full Polygon (for badly wrong masks)

When the model completely missed the wound or the mask shape is entirely wrong:

  1. Switch to "Full polygon" mode.
  2. Click to add vertices around the real wound area.
  3. Double-click or click near the first vertex to close the polygon.
  4. You can draw multiple polygons if the wound is fragmented.
  5. Click Compute Metrics to compare.

Controls

Mask overlay Toggle the red semi-transparent model mask on/off
Show edges Toggle the cyan (upper) and magenta (lower) boundary lines
Show fill Fill closed polygons with semi-transparent blue
Undo Remove the last vertex; if none, re-opens the last segment/polygon
Clear All Remove all corrections and polygons for this image
Compute Metrics Send corrections to the server and display Dice, IoU, etc.

Bulk actions

Approve QC-valid: sets all un-annotated images that passed automatic QC to "Correct".
Reject QC-invalid: sets all un-annotated images that failed QC to "Incorrect".
These only affect images without an existing verdict. You can always override a bulk verdict by selecting the image and clicking a different button.

Session & Export

All annotations are auto-saved to disk on every action. You can close the browser and resume later — progress is preserved.
Export Excel generates a workbook with two sheets: per-image annotations and aggregate summary statistics.
